# Audit E: repurposing screen, copy-number map, what's-new scan

*Independent fact-check, November 20, 2026. Reports were not edited. Each claim was checked against primary sources (PubMed E-utilities, Europe PMC, ClinicalTrials.gov API v2, bioRxiv/medRxiv API) or recomputed from the repository's data files with fresh scripts (scratchpad audit2/). Verdicts: CONFIRMED, WRONG, OVERSTATED, UNVERIFIABLE, INCONSISTENT.*

## File 1: reports/Approved drugs worth testing in osteosarcoma.md

Score recomputation: an independent script re-applied the stated formula (evidence, expression, druggability, untested, direction factor) to every row of `data/osteosarcoma_repurposing_candidates.csv`. All 1,141 totals reproduce to within 0.15 points, and the druggability points reproduce exactly from phase, oral route, paediatric trial count and boxed warning. `data/repurposing_raw/build.json` holds 2,400 drugs on 1,141 genes, and the cached ChEMBL files hold 4,225 phase 4 and 1,892 phase 3 molecules and 7,561 mechanisms, all as stated. There are 156 non-empty review notes.
