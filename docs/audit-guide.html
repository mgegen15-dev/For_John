Auditor's Guide

For a third-party reviewer. Version 1.0, frozen on November 23, 2026 (git tag v1.0). Check against that tag, not the live main branch, so that your findings line up with what you are reading.

This project makes many claims across 16 reports. This page lists the 18 that matter most: the ones the one-page summary, the website and the ranked leads depend on. For each one it gives where the claim is made, its primary source, and the fastest way to check it. If these hold, the project's main conclusions hold. If any fail, please tell us.

Before You Start

  • Get the frozen version: bash git clone https://github.com/mgegen15-dev/For_John bash cd For_John && git checkout v1.0
  • Set up: Python 3.10 or newer, plus pip install -r requirements.txt (only pandas).
  • Check the data is unchanged: run python3 tools/build_manifest.py and compare its output with the checksums in DATA_MANIFEST.md as committed at v1.0. Raw downloads are not in git, so they must be re-downloaded. Live databases change, so expect small differences from the retrieval dates listed there.
  • Read first: HOW_THIS_WAS_MADE.md (methods, limits, how AI was used) and SUMMARY.md (the claims in plain language).
  • Earlier internal checks: research_notes/Audit/ holds the AI-run audits and their findings. They are a record, not a substitute for your review.

Labels used in the reports: - (registry): an official database record. - (paper, full text): read in the full published paper. - (paper, abstract only): read only in the abstract. - (preprint, abstract only): an unreviewed preprint. - (press release only): no peer-reviewed source. - (our calculation): computed by this project.

Claims labelled abstract-only, preprint or press-release-only are the weakest, and the most worth checking.

Known Weak Points

These are the places we already know the work is weakest: - Abstracts, not full texts. Many papers could be read only as abstracts, because some publishers block automated access. - Keyword tagging. Paper types and trial scope were assigned by keyword rules. The internal audit found roughly 1 in 4 to 1 in 3 tags wrong in a small hand sample. - Gene mislabelling. Automated text mining mislabels some genes. A correction table is in tools/literature_map.py, but more errors likely remain. - Narrow registry coverage. ClinicalTrials.gov only; European-only and China-only registries were not searched systematically. - Unverified sources. Several leads rest on press releases or web listings: the Colorado State dog studies, and the OST-HER2 vaccine results. - Not independent people. All internal checks were run by AI models, not by independent people. Your review is the first independent check.
